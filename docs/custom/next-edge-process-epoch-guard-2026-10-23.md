# NEXT Edge — immutable process/Profile epoch guard (2026-10-23)

**Acceptance scope: source-only, synthetic offline verification. Not a production CDP/WebSocket peer attestor, qualified Edge connector, NEXT Browser Broker ExternalLeaseBackend or live UAT.** The installed NEXT remains `0.9.2-rc.5`; original Stable, running company Edge, credentials and browser pages remain untouched.

## Built primitive

- Added `newEdgeProcessEpochRevalidation` in `internal/tool/browser/external_edge_epoch_guard.go`. It creates a private callback compatible with the previously completed `externalFenceSeries` per-action revalidation contract. Callers must supply an independently obtained, **recent** `edgeProcessPreflight`, immutable `WorkerInfo`, opaque `externalPeerIdentity` and read-only `edgeProcessProbe` source. Constructor rejects absent/stale/future source, missing or typed-nil probe, unready worker, mismatched/empty peer identities, and wrong Edge executable.
- Every invocation re-runs existing bounded `readEdgeProcessPreflight`: exact canonical loopback listener & one process owner, Edge command/profile directory, OS PID **and start epoch**, mapped executable and signed Microsoft identity (disk and live), and repeated process/metadata observations. It compares the new result against immutable evidence captured at admission. Errors are sanitized to `externalTransportFenceError()`, and no browser pages, cookies, CDP tabs or profile contents are inspected.
- Extended `edgeProcessPreflight` with its already-observed metadata-only `edgeProfileMetadata` (owner, ancestor device/inode/mode) and reject any changed component **between** operations. This detects when a path name stays the same while a Profile parent or directory is replaced. No file contents are read. Existing preflight already compared the path metadata *within* each individual check; this addition binds it to the admission snapshot across multiple operations.
- The existing `externalFenceSeries` ensures this read-only callback runs **before** every fresh one-shot transport and **after** its owned connector closes. If the process incarnation, listener, metadata, signer, worker generation or opaque peer changes, the series permanently fails closed and quarantines the result. The callback does **not** mint the opaque peer identity: one must come from an independent trusted session attestor.

## Verified synthetic tests

`external_edge_epoch_guard_test.go` uses the existing fake macOS probes, never touches a user's installed Edge. It covers repeated same-process observations around **three operations** (initial admission plus six separate OS checks), PID start-epoch changes, listener rebound or changed owner, signer/image/command drift, Profile read denial and replaced Profile inode, constructor stale/future/invalid source and typed-nil provider, wrong worker/peer context without probing, cancellation, and **post-operation** drift withholding the already produced response after closing the owned connector. Browser/Profile/Config/App full Go regression and targeted repeated/race tests are required gates before merge.

## Precisely what is still missing

1. **Independent authenticated session attestor:** OS process+inode observations alone do **not** authenticate the user's existing Edge WebSocket session, logged-in Profile, user consent or CDP frame origin. The existing `edge-devtools-profile-ws` MCP in original Stable worked, but cannot be copied to NEXT and treated as qualified native Browser Broker status. Real `ConnectorStatusProvider` is still `nil` in NEXT Runtime; no production peer is minted.
2. **Atomic socket-peer binding:** the existing read-only established-socket preflight and experimental pinned connector need an independently reviewed socket-bound attestor that proves this **actual** WS connection is the inspected Edge incarnation. Non-atomic OS evidence around a request is insufficient to prevent all races, and a process PID/port is not proof of a live CDP WebSocket.
3. **Production multi-operation lease backend:** add owner-bound per-action attested factory and `ExternalLeaseBackend`, page ownership proof, cancellation/TTL and safe NEXT-only cleanup. Never close user-owned Edge processes or pages.
4. **User-authorized Host UAT:** restrict Oprueba/HomiPlay to specific approved HTTPS origins/workspaces; GitLab APIs with token remain first choice. Then use a versioned NEXT-only candidate, separately accepted installation, and scoped read-only Edge UAT. P13/P14 UX remains deferred.

**Failure is preferable to an unsafe fallback:** Until all production gates exist, company-required Edge routes must fail closed, not silently use Managed Chrome. This new primitive and its tests do not require an updated NEXT App or create a private browser route config file.
