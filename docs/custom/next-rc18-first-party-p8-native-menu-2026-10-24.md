## Concrete source-only native menu correction

- `AppDelegate.rebuildMenu` previously hardcoded the Stable product name in both normal and updating headings (`AgentDock: %@`), in mismatch status, and in the localized `Open / Set up / Stop / Restart / Start AgentDock` actions, even when the **validated NEXT bundle** was active. This is a real confusing control label; it does not mean the underlying controls were routed to Stable.
- Smallest source correction adds `AppIdentity.menuText(localizedText)`: for Stable return the already localized string byte-for-byte; for NEXT replace the existing literal `AgentDock` brand span with `AgentDock Next`. Applies only to the menu headings/commands above. All three supported macOS locales (zh-Hant, zh-Hans, en) already include exactly this brand in their existing translated strings, retaining their original grammar and status text. Anomaly status is branded **once at final menu title formatting**, avoiding an accidental `AgentDock Next Next` duplicate. No new i18n keys, icon changes, selectors, service commands, OAuth, Edge or process changes.
- `AppIdentityTests` gained Stable/NEXT assertions for native action labels, mismatch and unknown/non-branded strings. Standalone Swift executable tested **16 variant/case combinations PASS**. All **34** `AgentDockApp/Sources/*.swift` files passed `xcrun swiftc -typecheck` for macOS arm64 deployment target 13.0; only the **existing** `AppDelegate.swift` async `[weak self]` capture compiler warning remained. `git diff --check` PASS.
- **This is source-only, not installed RC18 Host PASS.** It has no effect on running RC18 GUI until another authorized, versioned native App build and Next-only deployment; deliberately avoiding gratuitous RC19 installation for cosmetic text. The outstanding Tray's blank `AXExtrasMenuBar` proxy title/description, uncertain true ownership and physical menu-click verification **remain OPEN**, unaffected by this menu text fix.
